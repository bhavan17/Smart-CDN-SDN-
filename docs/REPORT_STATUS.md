# Report status and evidence notes

This repository packages the code and prior evidence. It does not include a finished revised DOCX report because no DOCX report file was supplied in the source ZIP.

When writing the final report:

- Use `evidence/screenshots/`, `evidence/logs/`, and `results/` to explain what was recorded.
- Do not claim zero-loss failover, instant detection, migration of existing connections, or universal Adaptive superiority. A controlled NetEm latency-degradation experiment is now documented in results/generated/adaptive_degradation_20261027.md; its conclusions apply to that test run.
- Describe `latency_ms` from the committed monitor as TCP connection-establishment latency.
- Treat the existing 3-trial policy comparison as a small controlled experiment with considerable trial variability.
